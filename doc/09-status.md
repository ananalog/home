## Что не проверено и требует железа

1. **Прошивка на плате.** Первый шаг — `board-probe`: он покажет объём flash, пины экрана и найдёт датчик на I2C.
   Особенно проверить: экран на GPIO5/6 (у клонов бывает 8/9), смещение столбцов 28 для 72×40.
2. **ACD1200.** Команды взяты у семейства ACD (ACD10/ACD3100). Проверить чтение CO2 и CRC;
   шкалу «температуры датчика» уточнить по даташиту (сейчас отдаётся сырое значение).
   **Только через преобразователь уровней** — линии датчика подтянуты к 5 В.
3. **BLE ↔ Android** на реальном телефоне: код на экране, сканирование Wi-Fi, применение статического IP,
   OTA по BLE. Логика совпадает с протестированной в `core`, но GATT-слой проверяется только на устройстве.
4. **Сборка Android** — в CI GitHub (там есть SDK) или локально в Android Studio.
5. **Telegram и DuckDNS**: реальный бот, домен, сертификат Caddy, NAT loopback на роутере.

## Известные ограничения

- Поиск сервера прошивкой — UDP-широковещанием (работает в одной подсети). Если сервер в другой подсети —
  задайте адрес сервера в Android-приложении.
- UART-вариант драйвера ACD1200 не реализован (нужен даташит с командами UART).
- Шифрования нет (по решению): защита — firewall, ручное принятие устройств, код на экране для BLE.
- Mini App работает только через Telegram (вне Telegram — dev-режим сервера).
- Core dump с устройств на сервер не выгружается.

## Первый запуск по шагам

1. **Сервер** (x86_64, Debian/Ubuntu), на нём:
   ```
   git clone --recursive https://github.com/ananalog/home && cd home
   sudo scripts/server-bootstrap.sh --domain <имя> --duckdns-token <token> \
        --bot-token <токен бота> --admin <ваш telegram id> --firewall
   ```
2. **Релиз сервера** (на сервере или своём компьютере с .NET 10 и Node 22):
   `make deploy HOST=<user>@<ip-сервера>` (или `scripts/deploy.sh local` на самом сервере).
3. **Роутер**: резервация IP сервера, проброс 443 и 80 на него. Проверка: `https://<имя>.duckdns.org/healthz` → `ok`.
   Если 443 уже занят другим приложением — добавьте к `server-bootstrap.sh` флаг `--https-port 8443`,
   пробросьте 8443 на сервер, адрес будет `https://<имя>.duckdns.org:8443`.
4. **Бот**: в @BotFather → Bot Settings → Menu Button → `https://<имя>.duckdns.org`. Откройте бота → «Дом».
5. **Плата**: `firmware/scripts/fw-build.sh board-probe && firmware/scripts/fw-flash-usb.sh board-probe && firmware/scripts/fw-monitor.sh`.
   Если всё найдено — `fw-build.sh co2-egg` и `fw-flash-usb.sh co2-egg`.
6. **Настройка устройства**: Android-приложение → устройство рядом → код с экрана → Wi-Fi → (при желании статический IP).
7. **Принятие**: в Mini App появится «Найдено новое устройство» → «Принять», выбрать комнату.
8. **Люди**: `homectl users add <chat id> --role user` на сервере, или человек пишет боту — вы одобряете в Mini App.
9. **Обновления прошивки**: `make fw-publish HOST=<user>@<ip>` → Mini App → «Прошивки» → «Прошить».

Без железа всё, кроме пунктов 5–7, можно попробовать с эмулятором: `home-sim --count 3` на сервере.
