# Home — исследование и проектные решения

Система управления домашними устройствами: сервер в локальной сети, датчики и
исполнительные устройства на ESP32, Telegram Mini App и CLI для управления,
Android-приложение для настройки устройств по Bluetooth.

## Ключевые решения (кратко)

- **Сервер** — C#, .NET 10, ASP.NET Core: HTTP API, живые события (SSE), TCP-gateway устройств и бот в одном процессе;
  SQLite; self-contained single-file для linux-x64 под systemd. CLI `homectl` — Native AOT.
- **Устройства сами подключаются к серверу** по TCP (сервер находят UDP-запросом в сети), поэтому серверу не нужно
  знать их IP, а DHCP/статика — только вопрос настройки устройства. Шифрования в LAN нет (решение владельца).
- **Один бинарный протокол для TCP и BLE**: фрейм + TLV-поля, схема в YAML, генератор кода для C / C# / Kotlin.
  Тот же протокол используется для OTA — прошивать можно с сервера по Wi-Fi и с телефона по BLE.
- **Устройство описывает само себя** (набор «точек») — Mini App, CLI и Android рисуют интерфейс по описанию.
- **Прошивка на ESP-IDF**: OTA с автоматическим откатом, `factory`-раздел для отката к заводской прошивке,
  NimBLE, общий компонент `home_core` для всех устройств.
- **Доступ снаружи**: белый IP + DuckDNS + Caddy (Let's Encrypt). Вход — подпись Telegram `initData`
  + список пользователей, которым управляет админ через `homectl users add <chat_id>`.
- **Репозитории**: зонтик `home` + сабмодули `home-protocol`, `home-server`, `home-firmware`, `home-android`.
