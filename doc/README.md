# Home — исследование и проектные решения

Система управления домашними устройствами: сервер в локальной сети, датчики и
исполнительные устройства на ESP32, Telegram Mini App и CLI для управления,
Android-приложение для настройки устройств по Bluetooth.

## Ключевые решения (кратко)

- **Сервер** — один статический бинарник на Go (сервер + CLI + встроенная статика Mini App),
  SQLite, systemd. Работает на любом Linux (x86_64 / arm64, в т.ч. Raspberry Pi).
- **Устройства сами подключаются к серверу** по TCP (сервер находят через mDNS),
  поэтому серверу не нужно знать их IP, а DHCP/статика — только вопрос настройки устройства.
- **Один бинарный протокол для TCP и BLE**: фрейм + TLV-поля, схема в YAML,
  генератор кода для C / Go / Kotlin. Тот же протокол используется и для OTA —
  значит прошивать можно и с сервера по Wi-Fi, и с телефона по BLE.
- **Устройство описывает само себя** (набор «точек»: датчики, переключатели, настройки,
  действия) — Mini App, CLI и Android рисуют интерфейс по этому описанию, новый тип
  устройства не требует правок сервера и приложений.
- **Прошивка на ESP-IDF** (не Arduino): OTA с автоматическим откатом, `factory`-раздел
  для отката к заводской прошивке, NimBLE, общий компонент `home_core` для всех устройств.
- **Mini App доступен снаружи через Cloudflare Tunnel** (без белого IP и открытых портов),
  авторизация по подписи Telegram `initData` + белый список пользователей.
- **Репозиториев 4**: `home-protocol`, `home` (сервер + CLI + Mini App + деплой),
  `home-firmware`, `home-android`. Обоснование — в [01-architecture.md](01-architecture.md#разбиение-на-репозитории).
