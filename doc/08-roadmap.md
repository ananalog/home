# 08. Этапы работ и решения

## Этапы

| # | Этап | Результат |
|---|---|---|
| 0 | **Репозитории и протокол** | зонтик `home` + 4 сабмодуля; `schema.yaml`, генератор на C# (C + C#), тест-векторы; эмулятор устройства |
| 1 | **Сервер MVP + CLI** | gateway :7700, реестр, SQLite, `homectl devices/get/set/watch/users`; работает с эмулятором |
| 2 | **Прошивка MVP CO2** | `home_core`: Wi-Fi (настройки через menuconfig), mDNS, TCP-сессия, точки; драйвер ACD1200, экран, RGB-светодиод. Реальный датчик виден в CLI |
| 3 | **Mini App MVP + доступ** | авторизация initData, пользователи по chat id, Дом/Устройство/график; DuckDNS + Caddy; бот; `server-bootstrap.sh`, `deploy.sh` |
| 4 | **OTA** | OTA в протоколе, раздел factory, откат, дескриптор образа; `homectl fw …`, экран «Прошивки»; `fw-build/flash-usb/publish` |
| 5 | **BLE + Android MVP** | GATT-сервис в ядре, код на экране; приложение: поиск, Wi-Fi, DHCP/статика, сервер, сбросы, логи |
| 6 | **Полировка** | уведомления/пороги, запросы доступа через бота, OTA по BLE из Android, канареечная раскатка, бэкапы наружу, core dump |
| 7 | **Дальше** | автоматизации (CO2 > 1000 → включить вентиляцию), новые устройства (реле, климат), мост в Home Assistant/MQTT по желанию |

## Принятые решения (ответы на открытые вопросы)

| # | Вопрос | Решение |
|---|---|---|
| — | Язык сервера | **C# / .NET 10** (вместо Go) |
| 1 | Плата «Egg» | по поиску — 01Space ESP32-C3 0.42" OLED: 4 МБ flash, SSD1306 72×40 на GPIO5/6 (0x3C), WS2812B на GPIO2, кнопка BOOT/GPIO9. Подробно — [06](06-co2-egg.md). Подтвердить по фото платы |
| 2 | I2C или UART для ACD1200 | **I2C + преобразователь уровней** (выходы датчика подтянуты к 5 В); запасной вариант — UART + делитель. Обоснование — [06](06-co2-egg.md#i2c-или-uart--что-выбрать) |
| 3 | Железо сервера | x86_64 |
| 4 | Доступ извне | белый IP + DuckDNS, TLS — Caddy (Let's Encrypt), проброс 443/80 |
| 5 | Пользователи | несколько человек; `homectl users add <telegram_id/chat_id> --role …`, роли admin/user/viewer, запросы доступа через бота |
| 6 | Репозитории | зонтик `home` + `home-protocol`, `home-server`, `home-firmware`, `home-android` сабмодулями |
| 7 | Шифрование | не используется (LAN доверенная, отдельных сетей нет); BLE — код с экрана/кнопка от случайных соседей |
| 8 | Наклейки/QR | не нужны |

## Что ещё уточнить

- Фото платы с двух сторон — подтвердить, что это вариант с экраном на GPIO5/6.
- Имя домена DuckDNS и имя бота (для конфигов по умолчанию).
- Умеет ли роутер NAT loopback (иначе — локальная DNS-запись домена на LAN-IP сервера).
